# План реализации интерфейса терминала для браузера

## Анализ текущего состояния

- Используется библиотека xterm.js (пакеты `@xterm/xterm` и `@xterm/addon-fit`)
- Уже реализован базовый класс `OneTerminal` в `src/app/OneTerminal.ts`
- Поддержка регистрации пользовательских команд через `registerCommand()`
- Базовая обработка ввода: ввод символов, Backspace, Enter, Ctrl+C
- История команд с навигацией по стрелкам вверх/вниз
- Встроенные команды: `help`, `ls`, `clear`, `blure`
- Интеграция с 1С через `emitEventTo1C()` при выполнении команд

## План реализации улучшений

### 1. Редактирование строки ввода (High Priority)

#### Текущее состояние
- Реализованы: стрелки вверх/вниз, Backspace, ввод символов
- Отсутствует: перемещение курсора влево/вправо, Home, End, Delete

#### Реализация
- Добавить поддержку `ArrowLeft`, `ArrowRight` для перемещения курсора
- Добавить поддержку `Home` (начало строки) и `End` (конец строки)
- Добавить поддержку `Delete` (удаление символа под курсором)
- Обновить метод `redrawInput()` для позиционирования курсора вручную
- Использовать `terminal.write('\x1b[' + n + 'C')` для перемещения курсора вправо

### 2. Автодополнание команд (High Priority)

#### Реализация
- Обработать нажатие `Tab` в `OneTerminal.ts`
- Реализовать поиск подходящих команд по префиксу
- Добавить поддержку автодополнания путей файлов (опционально)
- При повторном нажатии Tab перебирать варианты
- Показывать возможные варианты после нажатия Shift+Tab

### 3. Улучшенная работа с буфером обмена (Medium Priority)

#### Реализация
- Поддержка `Ctrl+V` для вставки текста (в дополнение к существующему вводу)
- Поддержка `Ctrl+A` для выделения всей строки (выделение текста в xterm.js ограничено)
- Поддержка `Ctrl+K` для удаления до конца строки
- Поддержка `Ctrl+U` для удаления до начала строки

### 4. Поддержка дополнительных встроенных команд (Medium Priority)

#### Реализация
- `cd <directory>`: смена рабочей директории
- `echo <text>`: вывод текста
- `pwd`: вывод текущей директории
- `date`: вывод текущей даты и времени
- `whoami`: вывод текущего пользователя
- `env`: вывод переменных окружения

### 5. Визуальные улучшения (Low Priority)

#### Реализация
- Настройка темы по умолчанию (светлая/темная)
- Кастомизация цветов через CSS переменные
- Поддержка ANSI-цветов в выводе команд
- Настройка шрифта и размеров через конфигурацию

### 6. Расширяемая архитектура команд (Medium Priority)

#### Реализация
- Создать интерфейс `CommandPlugin` для плагинов
- Добавить систему загрузки внешних модулей команд
- Поддержка команд с аргументами и опциями
- Добавление справки для каждой команды

## Приоритеты и этапы реализации

### Этап 1: Критичные функции (4-6 часов)
- Редактирование строки (перемещение курсора)
- Автодополнание команд
- Улучшенная работа с буфером обмена

### Этап 2: Базовые команды (2-3 часа)
- Реализация стандартных команд bash
- Интеграция с файловой системой (если используется backend)

### Этап 3: UI/UX и расширяемость (4-5 часов)
- Настройка тем и стилей
- Адаптация под интерфейс 1С
- Расширяемая архитектура плагинов

## Технические детали

### Тестирование
- Проверка всех комбинаций клавиш
- Тесты встроенных команд

## Примечания
- Терминал должен интегрироваться в поле HTML документа внутри 1С
- Код уже настроен для отправки событий в 1С через `emitEventTo1C()`
- Поддержка истории команд частично реализована, требуется улучшение
- Цветовой стиль должен соответствовать интерфейсу 1С
