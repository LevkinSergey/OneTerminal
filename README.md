# OneTerminal

Терминал для интеграции в поле HTML документа внутри 1С

## Функционал

### Улучшенное редактирование строки
- Перемещение курсора влево/вправо (`ArrowLeft`, `ArrowRight`)
- Переход в начало/конец строки (`Home`, `End`)
- Удаление символа под курсором (`Delete`)
- Вставка текста из буфера обмена (`Ctrl+V`)
- Управление позицией курсора (`Ctrl+A`, `Ctrl+E`, `Ctrl+U`, `Ctrl+K`)

### Автодополнание команд
- Автоматическое завершение команд по нажатию `Tab`
- Показ возможных вариантов при повторном нажатии

### Встроенные команды
- `help` — вывод справки о доступных командах
- `ls` — вывод списка файлов
- `clear` — очистка экрана
- `cd <directory>` — смена директории
- `echo <text>` — вывод текста
- `pwd` — вывод текущей директории
- `date` — вывод даты и времени
- `whoami` — вывод текущего пользователя
- `env` — вывод переменных окружения

### Улучшенный пользовательский опыт
- История команд с навигацией (`ArrowUp`, `ArrowDown`)
- Поддержка Ctrl+C для прерывания
- Кастомизируемые стили и темы

## Сборка

```bash
npm run build
```

## Разработка

```bash
npm start
```
